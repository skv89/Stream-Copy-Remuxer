# Stream Copy Remuxer 1.4.1

Stream Copy Remuxer is a portable Windows application for remuxing batches of media files and, when compatibility requires it, transcoding video with carefully selected profiles.

## Download

[Download the portable Windows release](https://github.com/skv89/Stream-Copy-Remuxer/releases/tag/v1.4.1)

Only compiled portable application artifacts are distributed. Application source, tests, requirements, build scripts, and internal development records are not published.
